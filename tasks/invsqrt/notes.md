## 1. What the reference does (paper arXiv:2610.23832 §III.A, Eqs. 13–31)

`x` is 22 bits (`n_p = 10`, `width = 2n_p + 2`), `1 ≤ x ≤ 3,133,452`.

1. **Normalize**: count leading zero *pairs* `s` (unary, 10 flag qubits, one `init_and` per flag) and shift
   `x` in place by `2s` with flag-controlled lane rotations (CSWAPs), so `M = x_norm/2^20 ∈ [1,4)` and
   `1/√x = 2^(s−10)/√M`.
2. **Initial guess** `y0 ≈ 1/√M` (17 fractional bits): 4 cubic polynomials (intervals `[1,1.5) [1.5,2) [2,3) [3,4)`,
   coefficients from the paper's Ref. [29]) selected by the top 3 bits of `x_norm`. Coefficients are XORed in by
   Clifford `gf2_iadd` (free), then Horner with `delta = M − {1,1.5,2,3}` truncated to 14 bits:
   `r1 = c2 − T(c3·δ)`, `r2 = c1 − T(r1·δ)`, `y0 = c0 − T(r2·δ)`. Each `T(·)` is a column-truncated
   schoolbook multiply (`_add_row`: `init_and` partial products into scratch → `iadd` slice → `del_and` free).
3. **One Newton step** `p = T(y0·(3 − T(M·T(y0²)))) ≈ 2/√M` (square 28 bits, product 28+2 bits, result 29+1 bits),
   then **denormalize** `y1 = p·2^s` by 10 flag-controlled left rotations of a 40-bit register.
4. **Phase**: one `Z_POW` per bit of `y1` (F = 40 fractional bits of a turn): bit 39 → Z, bit 38 → S (free),
   bit 37 → T (1 T), bits 0..36 → 37 priced rotations.
5. **Uncompute** 1–3 in reverse (adders become subtractors, `init_and`→`del_and`).

### Qubit map (ids are allocated once and never reused across registers; `Q = 260` = sum of rows)

| ids | register | width | live for |
|---|---|---|---|
| 0–21 | `x` | 22 | input (holds `x_norm` between normalize and un-normalize) |
| 22–61 | `y1` (p = bits 22..51) | 40 | multiply_y0 → uncompute multiply_y0 |
| 62–71 | `flags` (unary s) | 10 | whole circuit |
| 72–74 | `selectors` (t_a, t_b, half) | 3 | whole circuit |
| 75–142 | `c0..c3` (17 each; c3 = constant, c2/c1 = r1/r2, c0 = y0) | 68 | horner → uncompute horner |
| 143–170 | `square` | 28 | square → uncompute square |
| 171–200 | `z` | 30 | multiply_m → uncompute multiply_m |
| 201–230 | `scratch` (AND products) | 30 | transient, every `_add_row` |
| 231–259 | adder carry workspace allocated inside `iadd`/`isub` | 29 | transient, every adder |

**59 of 260 qubits (23 %) are transient adder temporaries**, and another 17 (`c3`) hold a Clifford-loadable constant.

Grand total 7,735 Toffoli-like (6,915 CCX + 820 CSWAP). Shares: Newton step (square+multiply_m+correct+multiply_y0)
**61.5 %**, Horner initial guess **27.7 %**, denormalize **7.8 %**, normalize 3.0 %, rotations 3.2 % of C.
Compute and uncompute cost the same — **uncomputation is half the circuit** — and within the arithmetic,
**adders (62 %) cost more than the AND partial products (38 %)**.

Measured primitive costs (static, kickmix 0.1 builder): `iadd` of n bits = n−1 Toffolis + n−1 workspace qubits
(carries uncomputed by measurement); controlled `iadd` ≈ 2n+3; controlled classical-constant add = n+1; controlled
`left_rotate` of n qubits by *any* shift = n CSWAPs; `init_lookup` with k address bits = 2^k − 2 Toffolis
(+k workspace), `del_lookup` ≈ 2^(k/2)·2.5 Toffolis (k=8: 254 + 25; k=9: 510 + 41; k=6: 62 + 10).

## 3. Slack in the budget

* **Phase tolerance**: `tol(x) = 2^-24/√x` turns. The circuit's worst relative error is 2^-25.07 = **0.477 tol**
  (x = 2,588,411); it is deterministic (equals the classical model to the bit), so the 52 % headroom is real,
  not a seed artefact.
* **The binding error is the cubic initial guess, not fixed point**: with the reference coefficients and 14-bit δ,
  `y0` has relative error 2^-12.75; one Newton step turns e into ≈1.5e², i.e. 2^-24.9 in exact arithmetic
  (fixed point happens to land at 2^-25.07). A near-minimax cubic on `[1,1.5]` reaches 2^-13.98 and on `[1.5,2]`
  2^-16 in float, so **re-fitting the four cubics for the fixed-point pipeline could buy ~1–2 bits of y0 accuracy →
  2–4 bits at the output**, which would then pay for the precision cuts below.
* **Rotation budget**: `eps = π·min_margin/n_rot` is set by the smallest absolute margin (large x). Each rotation
  costs 27.28 T = 6.82 Toffoli-eq; the eps term is logarithmic, so halving the margin costs only +0.56 T per
  rotation (+5 Toffoli-eq total) while removing one rotation saves 6.8.
* **Precision knobs of `Precision()` (classical model, `err/tol` must stay < 1; Toffoli deltas from rebuilding)**:

  | change | err/tol | Toffolis | Q |
  |---|---|---|---|
  | baseline (14,17,28,28,29) | 0.477 | 7,735 | 260 |
  | delta_bits 13 | 0.602 | −114 | 0 |
  | delta_bits 12 | 1.012 ✗ | −234 | 0 |
  | coef_bits 16 | 1.340 ✗ | −302 | −4 |
  | square_bits 27 | 0.882 | −72 | −1 |
  | product_bits 27 | 0.920 | −90 | −2 |
  | result_bits 28 | 0.656 | −88 | −1 (and −1 rotation) |
  | best combo found: (14,17,27,27,27) | 0.953 | **−330** | −4 |
  | safer combo: (13,17,28,27,28) | 0.847 | −288 | −2 |

  So the *unchanged* architecture can shed ~4 % of its Toffolis just by trimming widths, and ~8 % if a better
  polynomial frees `coef_bits = 16`.
* **Low phase bits**: truncating (simply not applying) the j lowest `Z_POW`s of `y1` costs tolerance at large x:
  drop 2 → 0.552, drop 3 → 0.658, drop 4 → 0.838, drop 5 → 1.26 ✗. Each dropped bit saves one rotation (6.8 Toffoli-eq)
  but shrinks `min_margin`, raising all other rotations' cost; net ≈ −17 Toffoli-eq for 3 bits. Small.

## 4. Ranked optimisation candidates

Savings are *estimates* against C = 7,988 / Q = 260 (score 2.08e6); nothing is verified until
`scripts/verify.sh invsqrt …` says PASS. "Effect" is on the per-task cost Q×C.

| # | candidate | est. effect | risk / notes |
|---|---|---|---|
| 1 | **Replace Horner-cubic + Newton with one QROM-indexed piecewise quadratic** (paper §III.A explicitly suggests "a good polynomial approximation directly over the whole domain" and optimising the QROM-output coefficients). Address = top k = 8 bits of `x_norm` (256 bit-aligned pieces of [1,4)); float Chebyshev error 2^-27.7 (k = 9: 2^-30.7) leaves 3–6 bits for fixed-point truncation. `init_lookup` of (c2,c1,c0) ≈ 84 bits costs 254 Toffolis, `del_lookup` 25; two truncated 28×14-bit Horner multiplies ≈ 1,120 per direction (analytic `_add_row` model). Poly stage ≈ 2,800 total vs 6,902 now. With denormalize/normalize/rotations unchanged: **C ≈ 3,900 (−51 %)**. Q: drop `square`, `z`, `selectors`, `c3`, 17→28-bit coefs: `x` 22 + `y1` 40 + flags 10 + c2 28 (dead after step 1 → `del_lookup`, reuse as scratch) + r1 28 + scratch 28 + carries 27 + lookup 8 ≈ **190 → Q×C ≈ 7.4e5 (≈2.8× better)**. | **Highest value.** Needs a new `fixed_point_model`-style classical model and a brute-force check over all 3.1M x before building; coefficients should be minimax-fitted in fixed point per piece. Degree 3 at k = 6 (2^-29, ≈3,800) is the fallback if quadratic truncation error bites. First multiply (c2·δ) can run at ~22 bits because δ ≤ 2^-6 damps its error → another −150/direction. |
| 2 | **Qubit-id reuse without changing arithmetic**: `c3` (17 ids, 75–91) is a Clifford-loaded constant needed only during Horner; `square` (143–170) is live only between square and its uncompute; the two never overlap → alias 17 of `square`'s ids onto `c3` (reload `c3` by free XORs when the uncompute needs it). Also consider aliasing `selectors` into un-needed… (none free) and letting the `iadd` carry workspace overlap `scratch` bits that a given row does not use. | **−17 Q (−6.5 %) for 0 Toffolis**, very low risk; verify scratch returns to 0. Applies to the reference *and* to candidate 1 (where `c2`'s 28 ids become scratch after step 1). |
| 3 | **Binary s + barrel-shift denormalize** instead of 10 unary-controlled rotations of 30–31 qubits (300 CSWAPs each way). Thermometer-coded flags convert to 4-bit binary with CNOTs only (bit j of s = XOR of flags at indices t·2^j − 1 for t ≥ 1, since floor(s/2^j) = Σ_t [s ≥ t·2^j] and flag_i = [s ≥ i+1]); then 4 controlled shifts by 1,2,4,8 of the ≤40-bit register = 4 × ~40 = **160 CSWAPs/direction → −280 Toffolis total (−3.5 %)**, +4 qubits (or compute them into dead ids). Same trick on normalize (shift x by 2,4,8,16: 4 × 22 = 88 vs 110 CSWAP) is marginal. | Low risk; the flag→binary CNOT network is Clifford so cost is only the CSWAPs. Careful: `left_rotate` is cyclic, so the register must have ≥ 10 zero top bits (it does: 40 = 30 + 10). |
| 4 | **Newton step in residual form** (if candidate 1 is not adopted): `|ε| = |M·y0² − 1| ≤ 2^-11.75`, so `p = y0 − T(y0·ε)/2` needs only ~15–17 significant bits of ε and y0 instead of the full 17 × 30 `multiply_y0` (867) → ≈ 350–450/direction, and `correct` disappears (the sign is absorbed). Also copy y0 into p by CNOT (free). | ≈ **−900 Toffolis total (−11 %)**, −~13 qubits (z's high bits are known). Medium risk: needs the model extended with the new truncation; the full-precision product `M·y0²` must still be computed (cancellation). |
| 5 | **Re-fit the four cubics (or two + rescale) for minimax *relative* error in fixed point** and then cut `coef_bits` to 16 and `delta_bits` to 13; current y0 error 2^-12.75 vs 2^-14 achievable. | **−400…−600 Toffolis (−5…−8 %), −4 Q**; low risk (classical model decides; Clifford loader unchanged, only table values change). Prerequisite for squeezing candidate 4's widths too. |
| 6 | **Width trimming with the existing coefficients**: `Precision(14,17,27,27,27)` → 0.953 tol, −330 Toffolis, −4 Q; or `(13,17,28,27,28)` → 0.847 tol, −288, −2 Q. | **−4 % C**, trivial to build (just the dataclass), but 0.953 leaves only 5 % phase margin → rotation eps shrinks (≈ +6 T total) and no room for later truncation. Use the 0.85 variant unless combined with #5. |
| 7 | **Drop `correct`**: pre-set `z` to the constant `3` with X gates and have `multiply_m` *subtract* its rows (per-row truncation is sign-symmetric, so the result is bit-identical to `3 − T(M·y0²)`). | **−56 Toffolis (−0.7 %)**, zero risk. Subsumed by #1/#4. |
| 8 | **Skip the 2–3 lowest `Z_POW`s** of `y1` (truncate the phase): −2 rotations ≈ −13.6 Toffoli-eq at err/tol 0.552; −3 → −20 at 0.658, minus ~3–5 Toffoli-eq of eps penalty. | Tiny; only after everything else is fixed, since it eats the same margin candidates 1/5/6 want. |
| 9 | **Cheaper rows**: `_add_row` = ANDs into scratch + plain adder (≈ 2n−1 per row); kickmix's own controlled `iadd` costs 2n+3, so no win there. A dedicated controlled-add that fuses the AND into the carry computation (Gidney-style, ~1.5n) would cut the 2,142 adder Toffolis by ~25 % *and* remove the 30-qubit `scratch` register (−30 Q). | Medium-high effort (hand-written adder with `init_and`/`del_and`/HMR phase fix-ups), but applies to every design; potentially **−12 % C and −11 % Q** on top of #1. Prototype on one row and check `del_and` phase corrections under the verifier's seeded HMR. |
| 10 | **Pebbling / early uncompute of Horner intermediates** to free `c1/c2` (34 Q) during the Newton stage by recomputing them later. | Costs +2 × 357 Toffolis per freed intermediate for −17 Q each → *negative* at current C; only revisit if C drops below ~2,500 where Q dominates. Listed so nobody re-derives it. |

**Suggested order**: build the classical model for #1 (quadratic, k = 8/9, with #5-style minimax fitting and
#7's sign trick), confirm `max err/tol < ~0.8` over all x, then build it with #2 id-reuse and #3 barrel shift.
If #1 stalls, #5 + #6 + #4 + #3 + #2 + #7 on the reference architecture are worth ≈ −25 % C and −10 % Q
(≈ 1.5× on this task's ratio) with low risk.

## 5. Things to remember when building

* No Hadamard in the gate set: every value is a computational-basis function of `x`, phases only via `Z_POW`
  (hence no phase-gradient tricks); `HMR` is only for measurement-based uncomputation of Z-basis functions and its
  kickback must be fixed with `Z/CZ/CCZ/NEG`. `R` on a |1⟩ randomises the phase → every ancilla must be exactly 0.
* `Q = circuit.num_qubits` counts distinct ids ever mentioned, so `alloc_qubits`/`free` discipline (reuse ids) is
  what matters, not peak width.
* Rotation cost is only 3 % of C; do not spend Toffolis to save rotations unless the trade is < 6.8 Toffolis each.
* Smoke-test with `scripts/verify.sh invsqrt <file> --max-x 4096` (seconds), then the full run (~4 min); only the
  full run's `score` may be quoted.
